# Image Processing Service - Frontend

Frontend application for the Image Processing Service.

## Features

- User Registration
- User Login
- JWT Authentication
- Image Upload
- Image Preview
- Image Transformations
- Responsive UI

---

## Tech Stack

- React
- TypeScript
- Vite
- Axios
- React Router DOM

---

## Installation

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Preview build:

```bash
npm run preview
```

---

## Environment Variables

Create a `.env` file:

```env
VITE_API_URL=http://localhost:5000
```

For production:

```env
VITE_API_URL=https://your-backend-url.onrender.com
```
